# ❤️ Heart Disease Prediction using Python

## 📌 Project Overview

This project develops a machine learning model to predict whether a patient is at risk of heart disease based on clinical and demographic attributes. The objective is to compare multiple classification algorithms and identify the model that provides the most accurate predictions for early heart disease detection.

This project demonstrates the complete machine learning workflow, including data preprocessing, exploratory data analysis (EDA), feature preparation, model training, evaluation, and comparison.

---

## 🎯 Business Problem

Heart disease is one of the leading causes of death worldwide. Early identification of high-risk patients can improve clinical decision-making and patient outcomes.

The goal of this project is to build predictive models that assist healthcare professionals in identifying patients who may be at risk for heart disease using routinely collected medical information.

---

## 📊 Dataset

**Dataset: heart-disease-dataset

**Records:** 1,025

**Features:** 14

**Link:** https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset

### Variables

- Age
- Sex
- Chest Pain Type (cp)
- Resting Blood Pressure (trestbps)
- Cholesterol (chol)
- Fasting Blood Sugar (fbs)
- Resting ECG (restecg)
- Maximum Heart Rate (thalach)
- Exercise-Induced Angina (exang)
- ST Depression (oldpeak)
- Slope
- Number of Major Vessels (ca)
- Thalassemia (thal)
- Target (Heart Disease)

The following preprocessing steps were performed:

- Explored dataset structure and statistics
- Checked data types
- Identified duplicate records
- Removed duplicate observations
- Verified missing values
- Prepared data for model training

## 🤖 Machine Learning Models

Several classification algorithms were implemented and compared, including:

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)

Each model was trained and evaluated to determine its predictive performance.

---

## 📏 Model Evaluation

Performance was evaluated using:

- Accuracy Score
- Confusion Matrix
- Model Comparison

The objective was to identify the classifier that achieved the best predictive accuracy for heart disease classification.


---

## 📊 Results

The project compares multiple machine learning algorithms to determine the most effective model for predicting heart disease.

The evaluation highlights how different classification techniques perform on the same healthcare dataset, providing insight into model selection for medical prediction tasks.
